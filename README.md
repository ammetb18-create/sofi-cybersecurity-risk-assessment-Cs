# SoFi Technologies Cybersecurity Risk Assessment Case Study

## Independent GRC Analysis Based on Publicly Available Information

This project is an independent cybersecurity risk assessment case study of SoFi Technologies, Inc. The purpose of this project is to demonstrate practical skills in cybersecurity governance, risk management, control mapping, audit readiness, and executive-level security documentation.

The analysis focuses on cybersecurity risk areas that are commonly relevant to fintech companies, including access control, third-party/vendor risk, cloud and data protection, incident response readiness, monitoring, audit evidence, and regulatory exposure.

## Project Objective

The objective of this case study is to identify key cybersecurity risk areas, assess their potential business impact, map them to recognized security control categories, and recommend practical remediation actions from a GRC analyst perspective.

## Scope of Analysis

This case study focuses on:

- Cybersecurity risk assessment
- Access control and identity management
- Third-party and vendor risk
- Cloud and data protection
- Incident response readiness
- Security monitoring and audit logging
- Control mapping
- Remediation planning
- Executive-level reporting

## Deliverables

This project includes:

- Cybersecurity risk assessment overview
- Asset and data inventory
- Risk register
- Risk matrix
- Control mapping
- Gap analysis
- Remediation roadmap
- Executive summary
